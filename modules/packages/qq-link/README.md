# 平台内置 QQ 绑定

QQ 与 Minecraft 的身份绑定、游玩门槛、进退服事件上报和账号快照。源码随平台仓库放在 `modules/packages/qq-link`，不再从模块索引单独安装。

## 能力

| 能力 | 说明 |
| --- | --- |
| 绑定 | QQ 侧获取短码，在游戏内执行 `/c:bind` 后发送数字码 |
| 游玩门槛 | 未绑定玩家可进服，但暂时是访客，不能移动或交互；绑定成功后解除限制 |
| 状态与事件 | 向平台同步在线状态、玩家资料及游戏事件 |

聊天互通由聊天模块负责：频道可分别开启「转发到 QQ」，QQ 入站进入消息来源为 QQ 的频道。本模块不再读取已删除的 `bridge_channel_id`。QQ 机器人管理里也不再提供踢人。

## 绑定与入服

1. 在 QQ 对机器人发送「绑定」，取得短码。
2. 进入服务器，执行 `/c:bind`，在 60 秒内将纯数字短码发到聊天栏。
3. 绑定成功后，模块解除访客和移动限制。操作员恢复操作员权限，其他玩家成为成员。

模块启动时关闭原版 allow-list，以便未绑定玩家能进服完成绑定。若平台暂时无法确认绑定状态，新进入的玩家会继续受限。

安装时会创建 `configs/qq_link.json`。默认开启绑定门槛与入服审批；群管理员不会自动获得 SFMC 管理员权限。请在部署前核对该文件。
