# 接口与通信协议 · 导读

SFMC 依托伴生架构，在 Minecraft Script API（SAPI）与宿主 Node.js 数据中枢之间建立了高性能的本地通信桥梁。

本篇文档面向**需要进行跨模块调用的业务开发者**，以及**开发 Node.js 扩展工具或调试底层的架构师**。

```mermaid
  A --> C[SDK 导读 (SAPI 首选)]
  C --> D[模块服务目录 (RPC)]
  A --> E[平台 HTTP API (底层/调试)]
```

## 1. 基础端点与网络边界

- **服务基础地址（Base URL）**：`http://127.0.0.1:3001`
- **监听模式**：仅限本机本地回环接口（Loopback Only）。
- **端口配置**：定义在 `configs/db_config.json` 的 `db_port` 字段（可通过环境变量 `DB_PORT` 动态覆盖）。

```bash
# 本地服务连通性与健康度快速探测
curl http://127.0.0.1:3001/api/health
```

## 2. 交互分轨：走 SDK 还是直连 HTTP？

| 业务场景 | 官方标准做法 | 禁忌与原则 |
| :--- | :--- | :--- |
| **编写 SAPI 游戏业务模块** | **必须统一使用 `@sfmc-bds/sdk`** 提供的抽象封装。<br/>- 数据库：`@sfmc-bds/sdk/sapi/db`<br/>- 私有配置：`@sfmc-bds/sdk/sapi/config`<br/>- 跨模块调用：`@sfmc-bds/sdk/sapi/service` | **绝对禁止直接通过 SAPI fetch 直连 `127.0.0.1:3001`**。SDK 会自动处理请求签名、身份注入与网络异常重试。 |
| **Node.js 侧扩展与外部脚本** | 可直接发起 HTTP REST 请求（参考本节各平台 HTTP 子路由）。 | 需在 Request Header 中显式携带 Bearer Token。 |
| **查阅强类型签名** | 参阅自动生成的 [SDK 类型参考手册](../reference/index.md)。 | — |
