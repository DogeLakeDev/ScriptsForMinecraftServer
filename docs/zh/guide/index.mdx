# 入门

本页面向运维人员与模块开发者。读完后，您应能：

- 完成安装与首次初始化
- 使用常用命令管理服务与模块

## 系统要求

| 项目     | 要求                           |
| -------- | ------------------------------ |
| 操作系统 | Windows 10 + / Linux           |
| Node.js  | [22.13 +](https://nodejs.org/) |

## 快速开始

<Tabs>
  <Tab label="pnpm">

```bash
pnpm i -g @sfmc-bds/sfmc@beta
mkdir my-folder && cd my-folder
sfmc
```

  </Tab>
  <Tab label="npm">

```bash
npm i -g @sfmc-bds/sfmc@beta
mkdir my-folder && cd my-folder
sfmc
```

  </Tab>
</Tabs>

:::tip 提示
目前请使用 `@beta` 安装。  
可设置`SFMC_ROOT`环境变量来更改工作目录。  
:::

## 使用

首次运行会进入初始化向导。完成后工作目录大致如下：

```text
{工作目录}/
├── {BDS}/
├── configs/
├── data/
├── packs/
└── modules/
```

在sfmc交互终端内，键入“/”即可查看命令面板，使用键盘进行操作。

```bash
sfmc> /start -all # 启动所有服务
```

键入`TAB`可在不同的日志源中切换。

## 安装模块

```bash
sfmc> mod search
sfmc> mod install afk
sfmc> mod enable afk
```
