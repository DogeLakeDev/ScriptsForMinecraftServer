## 系统要求

在开始之前，请确保您的运行环境满足以下要求：

| 项目 | 最低要求 | 推荐配置 |
| :--- | :--- | :--- |
| **操作系统** | Windows 10 / 11, Linux (Ubuntu 20.04+, Debian 11+) | Linux (云服务器长期运行) / Windows (本地调试) |
| **Node.js** | `v22.13.0` 或更高版本（需内置 SQLite 支持） | 最新 LTS 版本（Node ≥22.13） |
| **包管理器** | `npm` 或 `pnpm` | `pnpm` |
| **磁盘空间** | ≥ 2 GB（用于存放 BDS 核心、行为包、备份与数据存档） | SSD 固态硬盘 |

## 快速安装与初始化

SFMC 提供了全局编排 CLI 工具，可实现从 BDS 自动下载配置到模块启停的全流程管理。

### 步骤 1：全局安装 SFMC CLI

<Tabs>
  <Tab label="pnpm (推荐)">

```bash
pnpm add -g @sfmc-bds/sfmc@beta
```

  </Tab>
  <Tab label="npm">

```bash
npm install -g @sfmc-bds/sfmc@beta
```

  </Tab>
</Tabs>

:::tip 提示
当前版本处于公测阶段，请务必添加 `@beta` 标签进行安装。如需在特定文件夹持久化数据，也可通过配置 `SFMC_ROOT` 环境变量指定自定义工作目录。
:::

### 步骤 2：创建服务器工作区并启动向导

创建一个专用的服务器目录，并直接运行 `sfmc`：

```bash
mkdir my-minecraft-server
cd my-minecraft-server
sfmc
```

首次运行会自动启动交互式初始化向导，完成以下准备工作：
1. 下载并解压适配当前系统的官方原版 Bedrock Dedicated Server。
2. 自动生成标准目录结构并注册默认配置文件与 JSON Schema。
3. 初始化轻量 SQLite 数据持久化守护服务（`db-server`）。

初始化完成后的目录结构如下：

```text
my-minecraft-server/
├── BedrockDedicatedServer/  # BDS 核心服务端程序
├── configs/                 # 平台与各功能配置文件（db_config, qq_config 等）
├── data/                    # SQLite 数据库与运行时状态
├── packs/                   # 自动组装输出的行为包产物目录
└── modules/                 # 已下载与启用的功能模块包
```

## 常用运维指令

SFMC 内置了现代化的交互式终端面板（REPL），也支持在宿主 Shell 中直接调用子命令：

### 1. 服务控制

在 `sfmc` 终端内输入 `/` 即可唤起交互式命令菜单：

```bash
# 启动全部服务（db-server + qq-bridge + BDS）
sfmc> /start -all

# 仅启动 BDS 或查看运行状态
sfmc> /start bds
sfmc> /status

# 平滑停止所有服务
sfmc> /stop -all
```

:::info 快捷键操作
在 REPL 交互界面中，直接按下键盘上的 `TAB` 键可以在不同的日志源（BDS 主控、数据库服务、QQ 桥接）之间实时无缝切换。
:::

### 2. 模块发现与安装

SFMC 拥有开箱即用的模块分发生态，可一键安装常用功能模块（如挂机检测、经济系统、传送点管理等）：

```bash
# 在官方模块索引中搜索模块
sfmc> mod search

# 安装指定模块
sfmc> mod install afk

# 启用并加载模块
sfmc> mod enable afk

# 热重载行为包代码（无需重启 BDS）
sfmc> mod reload
```
