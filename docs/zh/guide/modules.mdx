# 模块

本页说明运维侧如何安装、启停模块，以及行为包如何部署到世界。开发、发布见 [模块开发](../dev/module-author.md)。

模块是运行在原生 BDS 上的 SFMC 业务功能包，制品发布在 npm（`@sfmc-bds/module-<id>` 或 `@<author>/sfmc-module-<id>`）。[`sfmc-modules`](https://github.com/Tanya7z/sfmc-modules) 仓库仅提供检索用 index，不含业务源码。

## 安装与启停

```bash
sfmc> mod search
sfmc> mod install afk economy
sfmc> mod uninstall afk
sfmc> mod list
sfmc> mod enable afk
sfmc> mod disable afk
```

`mod enable` / `mod disable` 写入 `modules/module-lock.json`，不依赖 db-server。db 在线时会热同步内存态；db 未起时仍成功，下次 `start db` 后再跟上。要让游戏内行为包生效，通常还需 `mod reload` 或重启 BDS。

## 行为包装配

已启用的模块会打成一份行为包（及配套资源包），部署到当前世界。

```bash
sfmc> mod build
sfmc> mod reload
sfmc> mod reload --build-only
```

| 命令                      | 作用                                         |
| ------------------------- | -------------------------------------------- |
| `mod build`               | 仅构建，不部署                               |
| `mod reload`              | 构建、部署，并向 BDS 请求 reload（开发常用） |
| `mod reload --build-only` | 只构建并部署；之后需在游戏内手动 `reload`    |

`start bds` 前会自动比对装载 catalog（见 [服务管理 · 装载闸门](./services.md#装载闸门)）。不一致时会先整包重编并部署，成功后才启动 BDS。

### 部署路径

| 阶段         | 位置                                                        |
| ------------ | ----------------------------------------------------------- |
| 构建中间产物 | `packs/_build/sfmc-modules/`（及配套 RP）                   |
| 部署目标 BP  | `<BDS>/worlds/<level>/behavior_packs/sfmc-modules/`         |
| 部署目标 RP  | `<BDS>/worlds/<level>/resource_packs/sfmc-modules-rp/`    |
| 装载 catalog | BP 内 `sfmc-deploy-catalog.json`                            |

第三方附加包走 `packs` 收件箱，见 [附加包](./addons.md)。模块自带、经 `packs` 分发的世界 BP/RP 与 `sfmc-modules` 组装包是两条线。

<Steps>
### 扫描 `modules/packages/*/sapi`
### 仅打包 lock 中已启用的模块
### esbuild 构建并组装 BP/RP
### 复制到世界目录并写入启用清单
</Steps>

未启用任何模块时，仍会生成合法空包。

## 开发联调

作者在本地仓用 VS Code / Cursor 扩展「SFMC Module」开发；运维机在 SFMC 根目录执行：

```bash
sfmc mod install <id> --from dir:<作者仓绝对路径> --link
sfmc mod enable <id>
sfmc mod reload
```

`mod install` 须带模块短名。模板、Watch、发布流程见 [模块开发](../dev/module-author.md)。

## 制品来源

| 来源              | 用途                            |
| ----------------- | ------------------------------- |
| `npm:@scope/name` | 默认（index 的 `npm` 字段优先） |
| `dir:` / `local:` | 本地目录或归档；联调用 `--link` |
