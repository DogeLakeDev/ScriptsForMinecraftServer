# 模块

模块是基于原生 BDS 的 SFMC 业务功能包。制品在 npm（`@sfmc-bds/module-<id>` 或 `@<author>/sfmc-module-<id>`）。  
[`sfmc-modules`](https://github.com/Tanya7z/sfmc-modules) 只提供检索用的薄 index，不含业务源码。

## 安装与启停

```bash
sfmc> mod search
sfmc> mod install afk economy
sfmc> mod uninstall afk
sfmc> mod list
sfmc> mod enable afk
sfmc> mod disable afk
```

`enable` / `disable` **先写** `modules/module-lock.json`（不依赖 db-server）。db 在线时会 best-effort 热同步内存态；未起 db 仍成功，并提示下次 `start db` 后再跟上。要让游戏内行为包跟上，通常还需要 `mod reload` 或重启 BDS。

## 行为包装配

已启用的模块会打成一份行为包（及配套资源包）部署到当前世界。

```bash
sfmc> mod build
sfmc> mod reload
sfmc> mod reload --build-only
```

| 命令                      | 作用                                         |
| ------------------------- | -------------------------------------------- |
| `mod build`               | 仅构建，不部署                               |
| `mod reload`              | 构建、部署，并向 BDS 请求 reload（开发常用） |
| `mod reload --build-only` | 只构建并部署；之后需在游戏内手动 `reload`    |

`start bds` 前会自动比对装载 catalog：不一致则先整包重编并部署，成功后才启动 BDS。

### 路径

| 阶段 | 位置 |
| ------ | ------ |
| 构建中间产物 | `packs/_build/sfmc-modules/`（及配套 RP） |
| 部署目标 BP | `<BDS>/worlds/<level>/behavior_packs/sfmc-modules/` |
| 部署目标 RP | `<BDS>/worlds/<level>/resource_packs/sfmc-modules-rp/` |
| 装载 catalog | BP 内 `sfmc-deploy-catalog.json` |

第三方附加包仍走 `packs` / 收件箱，见 [附加包](./addons.md)。模块自带的世界 BP/RP 资源若通过 `packs` 分发，也归附加包流程，与 `sfmc-modules` 组装包分开。

流程简述：扫描 `modules/packages/*/sapi` → 仅打包 lock 中已启用的模块 → esbuild → 组装 BP/RP → 复制到世界目录并写入启用清单。一个模块都未启用时，仍会生成合法空包。

## 开发联调

作者侧用 VS Code/Cursor 扩展「SFMC Module」的 **Start Watch** / **Reload to BDS** / **Enable / Disable Module**（设置 `sfmc.root` 为含 `configs/`、`modules/` 的工作目录；扩展会把模块启停写入 `${sfmc.root}/modules/module-lock.json`，与 CLI 同源）。运维机：

```bash
sfmc mod install <id> --from dir:<作者仓绝对路径> --link
sfmc mod enable <id>
sfmc mod reload
```

`sfmc mod install` 须带模块短名。模板与发布流程见 [模块开发](../dev/module-author.md)。
