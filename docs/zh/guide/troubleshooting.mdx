# 排障与诊断

当遇到服务无法启动、模块未生效或连接异常时，可通过下方的交互式排障向导逐步排查；完整排查清单与高频问题汇总亦收录在下方，便于快速检索与定位。

## 常见问题排查清单

### 1. 端口冲突与网络异常 (Port Conflicts)

| 冲突端口 | 涉及服务 | 典型报错 / 现象 | 解决方案 |
| :--- | :--- | :--- | :--- |
| **`19132` (UDP)** | BDS 主控程序 | BDS 启动失败、崩溃或提示端口无法绑定 | 检查后台是否有僵死或残留的 `bedrock_server` 进程；Windows 使用任务管理器/netstat 结束对应 PID。 |
| **`3001` (TCP)** | db-server 数据服务 | 启动日志输出 `EADDRINUSE :::3001` | 在 `configs/db_config.json` 中调整 `db_port`，或通过环境变量 `DB_PORT=3011` 换用其他可用端口。 |
| **`3002` (TCP)** | qq-bridge (LLBot WS) | LLBot 连接失败，反向 WS 拒绝连接 | 确认防火墙已放行对应端口，并确保未同时运行多个 QQ 桥接实例。 |

```bash
# Windows 查看端口占用 PID
netstat -ano | findstr 19132

# Linux / macOS 查看端口占用
lsof -i :3001
```

### 2. 数据库守护服务（db-server）异常

| 异常现象 | 核心根因 | 解决步骤 |
| :--- | :--- | :--- |
| 启动瞬间秒退、报 `Cannot find module 'node:sqlite'` | Node.js 版本过低 | 将 Node.js 升级至 **`22.13.0` 或更高版本**（平台依赖 Node 内置的原生 SQLite 模块）。 |
| 数据持久化写入失败或报 `SQLITE_CORRUPT` | 磁盘异常或非正常断电损坏 | 停止所有服务，从 `<SFMC_ROOT>/data/backups/` 备份文件夹中还原最近的 `.sqlite` 文件。 |
| SAPI 模块调用数据服务报 `401 Unauthorized` | 模块鉴权 Token 失效 | 确认 SAPI 启动阶段 `ConfigManager.init()` 顺利获取了启动快照，重新执行 `mod reload`。 |

```bash
# 测试本地 db-server 健康度状态
curl http://127.0.0.1:3001/api/health
```

### 3. BDS 启动与行为包装载闸门

1. **查看装载摘要**：检查终端控制台的装载输出与 `<SFMC_ROOT>/.sfmc/logs/` 下的各服务独立日志。
2. **手动编译打包验证**：在 sfmc 终端中执行 `mod build`，确认 esbuild 产物生成无 TypeScript 语法报错。
3. **确认附加包冲突**：检查 `worlds/<level>/behavior_packs/` 是否存在同名或旧版行为包残留（详见 [附加包管理](./addons.md)）。

---

### 4. 模块已启用（Enabled）但在游戏内无响应

- **代码与配置生效边界**：
  - 若修改了 `sapi/src/` 中的 TypeScript 代码：执行 `sfmc> mod reload` 即可热重载生效。
  - 若修改了 `configs/*.json` 或 `manifest.json`：必须**重启 BDS** 才能生效。
- **锁文件状态**：确认 `<SFMC_ROOT>/modules/module-lock.json` 中该模块的 `enabled` 字段为 `true`。
- **生命周期时序问题**：若模块在初始化阶段操作了实体或维度数据失败，检查 `ModuleRegistry.register` 是否应设置 `afterWorldLoad: true`。
- **前置依赖模块**：检查 `manifest.json` 中的 `dependencies` 是否均已安装且处于 `enabled` 状态。

---

### 5. QQ 机器人与消息桥接异常

<Tabs>
  <Tab label="官方开放平台后端 (official)">

1. **凭证核对**：检查 `configs/qq_config.json` 中的 `qq_app_id` 与 `qq_app_secret` 是否正确填写。
2. **IP 白名单配置**：登录 QQ 开放平台开发者后台，确认公网 IP 已添加到调用白名单中。
3. **事件订阅**：确认在开放平台已开启 `GROUP_AT_MESSAGE_CREATE`（群聊 @ 消息事件）。
4. **群标识回填**：在群内首次 @ 机器人后，从控制台日志复制生成的 `qq_group_openid` 并填回配置文件，随后重启服务。

  </Tab>
  <Tab label="LLBot / OneBot 后端 (llbot)">

1. **反向 WebSocket**：确认 LLBot 配置文件中的反向 WebSocket 目标为 `ws://127.0.0.1:3002`。
2. **目标群号**：检查 `configs/qq_config.json` 中的 `qq_group_id` 是否为有效数字群号。
3. **防火墙拦截**：确认本机 3002 端口未被本地杀毒软件或安全策略拦截。

  </Tab>
</Tabs>

### 6. 模块热重载与 Watch 联调排查

| 现象 | 说明与排查应对 |
| :--- | :--- |
| 修改 `sapi/src` 源码后游戏内未生效 | 确认 VS Code 扩展 **SFMC: Start Watch** 处于运行状态；或在控制台手动执行 `sfmc mod reload` 触发重新打包与部署。 |
| 热重载提示成功，但新增命令无法响应 | 检查新命令的权限节点是否已在 `registerPermissions` 中声明；若修改了 `manifest.json` 权限节点或平台 JSON 配置，必须**重启 BDS** 才能生效。 |
