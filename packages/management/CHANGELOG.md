# @sfmc-bds/management

## 0.9.0

### Minor Changes

- f70f65b: 桌面端和小程序可以查看与编辑计分板。管理协议新增 `scoreboard.read`（全部计分项、参与者分数与显示位，可用 `after` 等待编辑后的新快照）和 `scoreboard.apply`（新建 / 删除计分项，设为 / 增加 / 减少 / 重置分数），握手带 `scoreboard` 能力时可用。读取来自 SDK 运行时同步到数据服务的快照：只在有人查看时上报，未变化时只发哈希；修改经 BDS 控制台的 `scoreboard` 命令下发，参数校验与命令生成在协议包的 `scoreboardOperationError` / `scoreboardCommand` 中。控制台命令无法定位离线玩家与实体，这两类参与者只读（`scoreboardTargetBlock` 给出原因）。db-server 新增 `POST /api/sfmc/scoreboard/live`（游戏内脚本上报）与 `GET /api/sfmc/scoreboard`，以及导出 `@sfmc-bds/db-server/scoreboard`。

## 0.8.0

### Minor Changes

- 20fefda: 桌面端和小程序可以查看行为日志模块（activity-log）的记录。管理协议新增 `activity.query`（按事件类型、分类、玩家、维度、级别、时间范围和关键词筛选，分页返回）和 `activity.stats`（记录数、活跃玩家、事件与级别分布），握手带 `activity` 能力时可用。平台以只读方式打开业务库查询，不需要重启后台进程；模块未安装时结果的 `installed` 为 false。db-server 新增导出 `@sfmc-bds/db-server/activity-log`，以及微信玩家查看本人记录的接口 `GET /api/sfmc/wechat/activity`，执行者固定为该微信绑定的游戏账号。

## 0.7.0

### Minor Changes

- e31e602: 配置页的「BDS配置」（server.properties）表单覆盖平台收录的全部属性，按基本、玩家、网络、性能、反作弊、脚本调试、诊断分组，并显示中文名称、说明、可选值与取值范围。平台读取 server.properties 时随 config.read 下发字段清单，桌面端和小程序使用同一份清单；旧平台没有字段清单时仍显示原来的常用字段。属性当前值不符合字段类型时，表单改用文本框或保留原值选项，不会改写原值。
- e31e602: 支持小程序微信登录与微信绑定。db-server 新增微信绑定表与 `/api/sfmc/wechat/bind/*` 接口，可按 openid 查询绑定、账号资料与 SFMC 有效等级；游戏内 `/c:bind` 改走统一入口 `/api/sfmc/bind/confirm`，按绑定码所属渠道确认 QQ 或微信绑定，旧接口 `/api/sfmc/qq/bind/confirm` 保留。SDK 的绑定确认优先调用统一入口，平台未升级时回退旧接口，并导出有效权限等级的计算函数。management 新增桌面端扫码登录链接的编码与解析（`sfmc://device-login`）。

## 0.6.0

### Minor Changes

- 4b60bb4: 日志可以按时间范围读取和删除。世界包可以读取图标、卸载、一次导入多个文件，并修改资源包清单版本。备份可以删除。模块索引会带上依赖名单；名单里的依赖必须已安装并启用后才能安装，索引没有该模块时仍按原来的方式安装。

## 0.5.0

### Minor Changes

## 0.4.0

### Minor Changes

- 配置页新增仅保存文件的 config.save 接口，保留语法、Schema 校验和版本冲突检查。模块安装、启停、卸载及世界包导入、启停不再自动停服或重启。三个页面提供独立重启按钮，只重启当前运行的服务；手动重启和下次启动时读取已保存的运行配置，并保留服务状态订阅。

  桌面发行支持独立构建号，保留产品版本并按构建号检查更新，界面显示为 0.3.6(1)。
