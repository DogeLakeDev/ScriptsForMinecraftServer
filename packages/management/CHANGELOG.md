# @sfmc-bds/management

## 0.5.0

### Minor Changes

- 取消普通维护任务和平台升级前的自动全量快照，新增 `backups.create` 手动备份接口与 `manual-backup` 能力标识。桌面端在“更新与备份”中提供手动备份按钮，保留历史备份的恢复能力。

## 0.4.0

### Minor Changes

- 配置页新增仅保存文件的 config.save 接口，保留语法、Schema 校验和版本冲突检查。模块安装、启停、卸载及世界包导入、启停不再自动停服或重启。三个页面提供独立重启按钮，只重启当前运行的服务；手动重启和下次启动时读取已保存的运行配置，并保留服务状态订阅。

  桌面发行支持独立构建号，保留产品版本并按构建号检查更新，界面显示为 0.3.6(1)。

## 0.3.3

### Patch Changes

- d18e066: 玩家页的允许名单改为展示绑定记录，包括玩家名、XUID、QQ 通道和绑定时间。名单只读，不写回原版允许名单。
- d18e066: 运行指标写入数据库。服务未运行时仍可查看已有曲线，并增加「一天」范围。

## 0.3.2

### Patch Changes

- fe9ab2e: 维护锁在持有进程已退出时自动失效并允许接管，避免界面卡在「进行中」；平台升级时先停服务再备份、最后再退出守护进程，并改为由维护进程自行写日志，防止 Windows 上父进程退出带走尚未脱离的子进程。

## 0.3.1

### Patch Changes

- 7b601f6: 运行指标增加内存与维度实体曲线。内存按主机总占用、BDS 和数据服务分色；维度实体按维度分色。

## 0.3.0

### Minor Changes

- 6bc2e42: 平台更新检查与接入计划返回对应固定版本的发行日志，桌面更新页和确认框展示更新内容。桌面端的便携版、预览版也能查看发行日志；检测到软件更新时在关于入口显示红点。更新确认携带目标版本，防止执行时切换到未经确认的新版本。

## 0.2.0

### Minor Changes

- a065cc4: 将 TPS、在线人数、维度实体数量与视距区块估算加入平台宿主的基础运行监控，提供受控指标读取、72 小时有界历史和主机内存、进程资源信息。桌面总览使用实际采样并区分断采、过期与未知状态。
- a065cc4: 增加版本化桌面管理协议、非交互 stdio 入口、持久化任务和跨进程维护锁；守护进程可由独立 Node 与显式 CLI 入口启动，保持原 CLI 协议兼容。

### Patch Changes

- 7aa43b0: 桌面正式发行提供 GitHub 构建证明和公开 SHA256，客户端通过发行页手动更新。将管理协议包纳入发行材料与版本验证清单。
